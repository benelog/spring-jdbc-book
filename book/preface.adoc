[preface]
== 저자 서문

Java 웹 개발에서 데이터 액세스 기술을 고르라면 많은 사람이 JPA를 먼저 떠올린다.
그런데 현장의 문제는 생각보다 자주 그 아래에서 생긴다.
복잡한 조회와 집계, 미묘한 트랜잭션 경계, 커넥션 풀의 병목처럼, 추상화가 감춰 주던 레이어가 갑자기 눈앞에 드러나는 순간들이다.
그때 필요한 것은 또 하나의 새로운 프레임워크가 아니라, SQL이 커넥션을 타고 흐르는 길을 끝까지 따라가 본 경험이다.

이 책은 그 길을 아래에서 위로 걷는다.
JDBC 표준 API에서 출발해 `JdbcTemplate`, 트랜잭션 추상화, Spring Boot의 자동 설정, Spring Data JDBC, 그리고 Spring JDBC Plus까지 한 레이어씩 쌓아 올린다.
레이어마다 "이 레이어는 아래 레이어의 어떤 불편을 해결하는가"를 먼저 묻고, 그 답을 코드로 확인한 뒤에야 다음 레이어로 올라간다.
추상화는 아래 레이어를 감추지만 없애지는 않기 때문이다.

예제는 처음부터 끝까지 암기 카드 앱 Flashcard 하나다.
장마다 서로 다른 예제 조각을 만나는 대신, 같은 앱이 장을 지날 때마다 자라나 마지막에는 간격 반복 복습과 통계까지 갖춘 앱으로 완성된다.
도구가 바뀔 때 무엇이 편해지고 무엇이 그대로인지는, 같은 문제를 다른 도구로 다시 풀어 볼 때 가장 선명하게 보인다.

원고에 실린 코드는 모두 저장소의 예제 코드를 그대로 참조한 것이다.
컴파일되고 테스트가 통과하는 코드만 책에 싣는다.
눈으로 읽는 데서 멈추지 말고, 직접 실행하고 고쳐 보며 읽기를 권한다.

독자로는 Java와 SQL의 기초를 아는 개발자를 생각했다.
JPA를 이미 쓰고 있지만 그 밑이 궁금한 사람, SQL 중심의 데이터 액세스를 처음부터 단단하게 배우고 싶은 사람 모두 환영한다.

어떤 프레임워크를 쓰든 결국 SQL이 커넥션을 타고 흐른다.
이 문장을 몸으로 아는 개발자는 어느 레이어에서 문제가 생겨도 내려가 볼 수 있다.
이 책이 그 감각을 익히는 여정이 되기를 바란다.
